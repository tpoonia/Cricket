# Data sources, licences, attribution

All data is either downloaded from an open source or generated by us. **No scraping** of
ESPNcricinfo, Cricbuzz or Getty (Hard rule #3).

| Source | What | Licence | Attribution |
|---|---|---|---|
| Cricsheet | `t20s_male_json.zip` (men's T20Is), `people.csv` register | **ODC-By 1.0** | "Data from Cricsheet (cricsheet.org), ODC-By." |
| Open-Meteo | Historical weather archive API | **CC BY 4.0** | "Weather data by Open-Meteo.com (CC BY 4.0)." |
| cricketdata (rOpenSci) | `player_meta` (bowling style, batting hand) | package licence (GPL-3) | "Player metadata via the cricketdata R package (rOpenSci)." |
| Synthetic images | Generated by us (SDXL / diffusers) | our own | Generator + licence recorded in `data/synthetic/manifest.csv`. |

## Download record
- `t20s_male_json.zip` — downloaded **2026-11-12**, 14.6 MB, 3,651 JSON files (3,650 matches + README). `last-modified: 2026-11-03`.
- `people.csv` — downloaded **2026-11-12**, 1.19 MB. Register with `key_cricinfo` used to join player metadata.

## Scope
**T20I men's internationals only.** No ODI/Test parts.

## Storage
- `data/raw/` — downloaded archives (git-ignored).
- `data/processed/` — tidy Parquet tables from ETL (git-ignored; regenerable).
- `data/manual/` — hand-filled CSVs (venue coords, manual player types) — committed.
- `data/synthetic/` — generated images + manifest; images git-ignored, manifest committed.
- `cache/` — cached API/weather responses keyed by content hash (git-ignored).

## Leakage policy
Every feature, venue prior, player value and simulator multiplier uses **only matches strictly
before** the match being evaluated, via `src/data/splits.py:history_before`. Enforced by a test.
